ChessNet - Version History
==========================

Current version: v0.6.0


v0.6.0 — Bug-fix release, two-player mode & quality-of-life
-----------------------------------------------------------

Fixed:
- Seven broken lesson positions (Discovered Check, Double Check,
  Queen Checkmate, Pin, Skewer, Fork, Trading Pieces) — several were
  unsolvable; all lesson content is now regression-tested.
- Lesson Hint no longer reveals the answer on the board.
- Closing the play/lessons window no longer leaves the app running
  invisibly; both windows return to the main menu (☰ Menu button,
  back button, or window close).
- AI worker threads are waited on close — no QThread crash risk.
- Move coaching runs on a worker thread (no UI freeze per move).
- Sound engine is actually created and wired to moves/captures/checks
  and game end — the ♪ button now does something.
- train.py rewritten: proper -1e9 legal-move masking, single forward
  pass per batch, masked top-1/top-5 metrics, ReduceLROnPlateau,
  early stopping, best-checkpoint saving, CPU-safe device handling.
- prepare_data.py wrapped in main() with script-relative paths and a
  friendly error when games.csv is missing.
- Clear error message when the checkpoint is missing.
- Board interaction blocked after game over; undo allowed after
  game over.
- Legacy tkinter GUI (chess_gui.py) no longer freezes while the model
  thinks — inference moved to a background thread with a stale-reply
  guard.
- Puzzle of the Day now really uses the UTC date as documented, so
  everyone gets the same puzzle on a given day.
- Promotion picker can no longer open partially off-screen.
- Player card material tooltip no longer sticks after the balance
  evens out.
- Main menu picks up theme changes made inside the play window when
  you return to it.
- Screenshot mode degrades gracefully when the model is unavailable.

Added:
- Two-player pass & play mode.
- Hint button in the play window (Ctrl+H) with policy confidence.
- PGN export (Ctrl+S).
- Animation toggle button.
- Settings persistence in ~/.chessnet_settings.json.
- Torch-free test suite (tests/) and GitHub Actions CI workflow.


v0.3.0 — Lessons Update
-----------------------

Added:
- Interactive Lessons mode with structured chess puzzles.
- Model Improved in different parts
- Live ChessNet coaching for wrong lesson moves.
- Ask AI button inside lessons to show the model's top candidate moves.
- Hint button inside lessons.
- Show me button to animate and display the correct lesson move.
- Reset button to restart the current lesson.
- Lesson progress tracking with solved-lesson checkmarks.
- Lesson navigation panel with all available lessons.
- Lesson keyboard shortcuts:
    * Ctrl+R  Reset current lesson
    * Ctrl+H  Ask AI for top moves
    * Ctrl+I  Show hint
    * Right   Next lesson
    * Esc     Back to main menu
- Lesson content is defined in chess_lessons.py.
- Lesson window is implemented in lessons_window.py.

Fixed:
- Lesson board pieces are now clickable in positions that python-chess
  marks as game over because of insufficient material.
- Improved BoardView mouse handling so pieces do not swallow click events.
- Improved lesson state handling so the board does not remain locked
  after wrong moves, AI hints, or answer animations.
- Improved board resizing so the board stays square and click targets
  remain aligned.


v0.2.0
------

Fixed:
- Sound toggle crash — sound button no longer crashes when toggled rapidly.
- AI worker thread lifetime properly managed — no thread leaks on game restart.
- Promotion drag-cancel fixed — dragging promotion piece off-board no longer crashes.
- AI inference runs on a worker thread so the UI never freezes.


v0.1.0
------

Initial desktop UI release.

Included:

- Model insights panel showing top-5 candidate moves.
